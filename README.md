## Conventions

- **No number without a source.** Every row in `outcomes.csv` carries
  `source_table_figure_page`.
- **Abstract-only data is flagged**, never silently pooled with full-text data.
- **No modelling before the protocol is frozen.** Analysis scripts are stubs until
  `protocol-v1.0` is tagged.
- **Scripts are numbered and idempotent**: each reads from the previous stage's
  output and writes only to `data/derived/` or `outputs/`.
